# GarmentPulse - Bangla Review Sheet

**Project:** GarmentPulse
**Course:** CSE327, Group 2
**Document purpose:** This file is a work sheet for a **Bangla speaker** who is not on the team. It lists every Bangla word and sentence that the apps show today, next to the English, so that one person can read them, mark the good ones, and correct the rest. It also asks for the Bangla spelling of the test names. Anyone reading it later can see what was reviewed and what was changed.

**Related documents:**

- [mvp.md](mvp.md) - section 5: the Bangla and English check is one of the MVP goals.
- [demo-and-test-plan.md](demo-and-test-plan.md) - tests T15 to T17 cannot be ticked until a Bangla speaker has done this sheet.
- [design-system.md](design-system.md) - the app is for factory workers, so the words must be simple.

## 1. For the person who reviews (please read this first)

**What GarmentPulse is:** a phone app and a website for garment factories. When a sewing machine breaks, a worker reports it, a manager sends a free technician, the technician fixes it, and the owner watches.

**Who reads these words:** factory workers, technicians, managers and the owner in Bangladesh. Many are busy and not used to apps. Please judge each Bangla text by this question: **"Would a factory worker understand this at once, without thinking?"**

**How to review:**

1. Read each row. The English is what we meant. The "Draft Bangla" is a first try written by the team, **not by a native speaker**.
2. If the Bangla is good, put an **x** in the **OK?** box: `[x]`.
3. If it sounds wrong, stiff, too formal, or confusing, write a better version in the last column. Leave **OK?** empty.
4. If you are not sure, write a short note in the last column.

**What we prefer:**

- Simple, everyday Bangla, the way people talk at work. Not formal or bookish.
- Words that people already use in a factory are fine, even if they come from English (for example: ম্যানেজার, টেকনিশিয়ান, মেশিন).
- Keep **polite but short** sentences. Buttons must be a few words.
- Keep the **same word for the same thing** everywhere (for example, always the same word for "report").
- Do not change the meaning. If an English sentence seems wrong or unclear, tell us in the note.

You do **not** need to know anything about software. You only need to read Bangla.

**When you finish:** send the filled sheet back (a photo of a printed page is fine). Thank you!
